Open source · Indian equities

BSK Stock Analyser

Design, build and accessibility auditPublic repository

Overview

A decision-support tool for Indian equities on the NSE and BSE. It pulls live price history and fundamentals, computes technical, trend, risk and valuation metrics deterministically, and produces a weighted score with an explicit decision, a confidence level and a data-quality reading.

Problem

Two problems, really. Fetching market data straight from the browser runs into CORS and leaves fundamentals out of reach entirely. And tools in this space tend to present a number without showing how confident it is or how good the underlying data was.

Approach

  • Static frontend plus serverless functions that proxy the data source server-side — which removes the CORS problem and unlocks fundamentals such as P/E, P/B, ROE, margins, debt and cash flow.
  • Scoring is deterministic and weighted, and the app surfaces its own confidence and data quality alongside every result.
  • A markets dashboard computed from the tracked universe: gainers and losers, most active by value and volume, volume shockers, near 52-week highs and lows, sector trends and a market-breadth bar.
  • Graceful degradation: on plain static hosting without the functions, price data falls back to public relays and fundamentals report as unavailable rather than being invented.

Interface

  • A bespoke design system — custom logo, hand-built SVG icon set, Sora / Inter / JetBrains Mono, an emerald-on-carbon palette with a gold signal accent.
  • Light and dark themes, and a circular score gauge as the primary read.
  • Keyboard and screen-reader support throughout: ARIA tabs and combobox, a skip link and reduced-motion support.

Result

  • An automated Playwright and axe-core audit reports 0 accessibility violations across the landing page and dashboard, in both themes.
  • Verified responsive at 375, 768 and 1280 px.

Duplicate CSS selector merger

Published VS Code extension

Problem

Large stylesheets accumulate duplicate selectors, which makes them harder to reason about and maintain.

Approach

  • Finds rules with identical property sets, regardless of selector name or the order declarations appear in.
  • Merges them behind a diff preview, so the change is reviewed before it is applied.

Result

Improved stylesheet maintainability in the editor, where the work actually happens.
